Below, I simulate a rather quite annoying set of regression data.

set.seed(0510)
n <- 250
dat.q1 <- tibble(x1 = rnorm(n, mean = 50, sd = 10),
                 x2 = factor(sample(c("A", "B"), n, replace = TRUE)),
                 x3 = factor(sample(c("Control", "Treat"), n, replace = TRUE)),
                 x4 = factor(sample(c("Low", "High"), n, replace = TRUE), levels=c("Low", "High")),
                 x5 = rnorm(n, mean = 0, sd = 1),

                   2 * x1 +
                   # Categorical x2
                   (x2 == "B") * 10 +
                   # Categorical x Categorical (x3*x4)
                   (x3 == "Treat") * 5 + (x4 == "High") * 2 +

                   # Quantitative x Categorical  (x5*x6)

                   1.5 * x7 + 0.5 * x8 +

                   rnorm(n, mean = 0, sd = 15))

1.1 Part a

Fit the regression model.

\[\begin{align*} Y_i =& \beta_0 + \beta_1 x_{1i} + \beta_2 I(x_{2i}=\text{B})+ \beta_3 I(x_{3i}=\text{Treat}) + \beta_4 I(x_{4i}=\text{High}) +\\ & \beta_5 x_{5i} + \beta_6 I( x_{6i}=\text{Group2}) + \beta_7 x_{7i} + \beta_8 x_{8i}+\\ & \beta_9 (I(x_{3i}=\text{Treat}) ~\times~ I(x_{4i}=\text{High})) + \tag{Categorical $\times$ Categorical}\\ & \beta_{10} (x_{5i} ~\times~ I(x_{6i}=\text{Group2})) +\tag{Continuous $\times$ Categorical}\\ & \beta_{11} (x_{7i} ~\times~ x_{8i}) + \epsilon_i \tag{Continuous $\times$ Continuous} \end{align*}\]

1.3 Part c

Interpret the intercept, the coefficients on \(x_1\) and \(x_2\).

Solution

The intercept \(\beta_0\), is the expectation of \(Y\) in the absence of any other continuous or categorical features of the model. Thus it’s what the model expects of \(Y\) if all continuous variables (\(x_1,x_5,x_7,x_8\)) are \(0\), and all of the categorical variables \((x_2,x_4,x_6)\) are \(0\), meaning that the observation is not in any of the categories. The coefficient \(\beta_1\) indicates the increase in the expectation of \(Y\) for a per unit increase in \(x_1\), while the coefficient \(\beta_2\) is the increase in expectation of \(Y\) due to membership in category B.

Solution

the coefficient \(\beta_{11}\) refers to the expected change in \(Y\) for a unit increase in \(x_{7i}\) after adjusting for the simultaneous linear change in \(x_{8i}\) and vice versa.

\[\begin{align*} \frac{\partial Y}{\partial x_{7i}} &= \beta_7 + \beta_{11}x_{8i} \\ \frac{\partial Y}{\partial x_{8i}} &= \beta_8 + \beta_{11}x_{7i} \end{align*}\]

Since the slope of both variables is significantly positive for the entire range of observed variables and the lines are upward sloping, the interaction is positive and increasingly strong at higher values of both variables.

After standardization, a unit change represents a standard deviation change in the variable, simplifying the algebra:

  • \(z_{7i} = -1 \implies \beta_0 - \beta_7 + (\beta_8 - \beta_{11})z_{8i}\)
  • \(z_{7i} = 0 \implies \beta_0 + (\beta_8)z_{8i}\)
  • \(z_{7i} = 1 \implies \beta_0 + \beta_7 + (\beta_8 + \beta_{11})z_{8i}\)

Thus, an increase of \(1\) s.d of x_7 corresponds to an increase of \(3.29\) in the slope of standardized \(x_8\)

Cui and Mao (2025) investigate how freezing and cryogenic temperatures affect the strength, flexibility, stiffness, and internal breaking behavior of 3D-printed CF/PEEK composites.

Carbon fiber reinforced PEEK (CF/PEEK) is a high-performance composite used in 3D printing for aerospace, deep-sea, polar research. The researchers aimed to assess whether and how extremely cold environments impact this composite to understand how 3D-printed CF/PEEK performs in freezing conditions. This work would be important to understand its limits and develop preventative methods to protect against structural failures.

The researchers created fifteen 3D printed dog-bone-shaped test specimens and placed them in a chamber cooled with liquid nitrogen to \(25^\circ\text{C}\), \(-25^\circ\text{C}\), \(-75^\circ\text{C}\), \(-125^\circ\text{C}\), and \(-175^\circ\text{C}\). To test strength of the specimen, a machine pulled both ends of the specimen until it snapped.

In the table below, the researchers record the average tensile strength for three specimens from each temperature level.

Compute the estimates we derived using calculus in lecture 16: \[\begin{align*} \widehat{\beta}_0 &= \bar{y} - \widehat{\beta}_1 \bar{x}_1 \\ \widehat{\beta}_1 &= \frac{\sum_{i=1}^n (x_{1i} - \bar{x}_1)(y_i-\bar{y})}{\sum_{i=1}^n (x_{1i}-\bar{x}_1)^2}. \end{align*}\]

4.1 Part a

Simulate data to match regression assumptions in a loop that runs \(R=1000\) times. \[\begin{align*} x_i &\sim \text{Uniform}(a=0,b=10)\\ \epsilon_i &\sim \text{Gaussian}(\mu=0, \sigma=1)\\ y_i &= 2 + 1.5 x_i + \epsilon_i\\ n &= 30 \end{align*}\] In each iteration, fit a regression line to the data and store the coefficient estimates. Plot the resulting estimates. What do you notice?

Solution

Code 
regression.sims = function(r, n, error.dist) {
  beta0 = rep(0,times=r)
  beta1 = rep(0,times=r)
  for (i in 1:r) {
    dat = tibble(
      x = runif(n=n,min=0,max=10),
      e = error.dist(n),
      y = 2 + (1.5 * x) + e
    )
    mod = lm(y ~ x, data = dat)
    beta0[i] = coef(mod)[1]
    beta1[i] = coef(mod)[2]
  }

  list(
  tbl = regression.tbl(beta0,beta1),
  fig = regression.fig(beta0,beta1)
  )
 
}


regression.tbl = function(beta0,beta1) {
   tbl = tibble(beta0, beta1) |>
    pivot_longer(everything(), names_to = "parameter", values_to = "estimate") |>
    group_by(parameter) |>
    summarise(
      mean   = mean(estimate),
      sd     = sd(estimate),
      median = median(estimate),
      skew = e1071::skewness(estimate),
      kurtosis = e1071::kurtosis(estimate),
    ) |>
    knitr::kable(digits=2)
}

 pvt = tibble(beta0, beta1) |>

4.3 Part c

Simulate data to match regression assumptions in a loop that runs \(R=1000\) times. \[\begin{align*} x_i &\sim \text{Uniform}(a=0,b=10)\\ \epsilon_i &\sim \text{Cauchy}(m=0, s=1)\\ y_i &= 2 + 1.5 x_i + \epsilon_i\\ n &= 30 \end{align*}\] In each iteration, fit a regression line to the data and store the coefficient estimates. Plot the resulting estimates. What do you notice?

Solution

Code 
out = regression.sims(r=1000,n=30, error.dist= \(n) rcauchy(n))
(out$tbl)

Code 
(out$fig)

The estimates are no longer centered, and the coefficient of variation and skew are now sufficiently large such that the means cannot be reasonably interpreted to be representative of the population. Also, the incredibly high kurtosis indicates fatter tails, with a greater likelihood for outliers. This would explain the distortion in the x-axis in Figure 12. Taken together, the simulation suggests standard OLS is not appropriate for models with an error term sampled from a cauchy distribution with the given parameters.
